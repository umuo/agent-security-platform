# 样本预算与整项任务预算

每个 Attempt 使用 timeout_seconds、max_turns、max_tool_calls、max_tokens 和 max_total_tokens。整项任务另有累计上限与执行时长上限：

| 字段 | 默认值 | 范围 |
| --- | ---: | ---: |
| max_job_tokens | 120000 | 64～2000000 |
| max_job_turns | 500 | 1～12000 |
| max_job_tool_calls | 1000 | 1～24000 |
| max_job_seconds | 1800 | 1～86400 |

Worker 按确定的样本顺序执行，从持久化结果累计用量。新样本的实际上限取单样本上限与任务剩余额度的较小值；实际 max_tokens 也会缩小，可能低于创建任务表单的最低值 64。每个已执行样本的 result.execution_budget 记录实际额度，任务报告的 budget_usage 给出累计 tokens、turns、tool_calls 及完整性标记。

任务额度耗尽时，已完成结果和危险行为证据保留，尚未执行样本标为 INTERRUPTED／INCONCLUSIVE，任务为 FAILED 并给出 JOB_*_BUDGET_EXHAUSTED。不会把少测的样本算成通过，也不会自动重试耗尽任务。旧 Worker 无法绕过租约写入预算停止状态。

## 用量与费用边界

token 用量取自目标响应的 usage.total_tokens，必须是非负整数；OpenAI 兼容与 HTTP 工具循环适配器要求此字段。缺失、非法、响应丢失或请求异常意味着这一轮用量未知，Worker 保存已有证据后以 JOB_USAGE_UNAVAILABLE 停止后续样本，而不是按零收费继续运行。

HTTP 仅输出模式可以返回可选的 usage.total_tokens。未返回时，当前样本的回答与可确认泄漏证据仍保留，但整项任务失败，后续样本不执行。接入端须汇总该请求内部的全部模型用量。旧报告缺少新计数时显示用量不完整，不改写历史数据。

token 上限是按声明用量核算的停止条件，不是供应商账单的精确硬上限：输入 token 可能在响应后才得知，目标也可能声明超出剩余额度的用量。报告保留真实声明值而不截断；例如剩余 4 token 的请求返回 10，累计可能超过配置上限，随后立即停止。精确费用约束需同时配置模型供应商的额度与网关限额。

## 计数范围

OpenAI 模型模式的 turns 为平台发出的模型请求次数，HTTP 工具循环的 turns 为 Agent 步骤请求次数，HTTP 仅输出模式为一次外部请求；被测 Agent 内部的更多模型步骤不能由平台独立计数。SDK 固定回归使用 demo 的模型调用计数，不调用收费模型。fixture 不发模型请求，因此 turns 和 tokens 为零。

平台工具的 tool_calls 包含被拒绝或参数非法的调用请求；SDK 固定回归使用真实方法执行计数。报告只能覆盖这些已观测计数，不能保证目标内部未知业务工具符合全局额度。

整项时长从 Worker 开始执行该任务计算，不包含排队等待；使用单调时钟。每次 Inspect 执行共享剩余任务时间，截止信号覆盖编排和被测端调用。超时保存已观察到的效果，任务以 JOB_TIME_BUDGET_EXHAUSTED 失败，后续样本不执行。

这是本地执行的协作式取消，不是对远端进程的强制终止：已发出的远端请求可能继续运行，Inspect、文件写入或子进程的退出清理也可能稍晚于截止信号完成。被测端需同时配置自己的时间与副作用限制；不能把客户端取消当作已撤销业务操作。
